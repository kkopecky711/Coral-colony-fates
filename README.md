# Coral-colony-fates

Code for analyzing data extracted from orthophoto mosaics of five ~25m^2 reef plots in Moorea, French Polynesia. These data are collected as a part of the Moorea Coral Reef Long Term Ecological Research site. 

Datafiles are provided in this repository, as well as code for each individual analysis and visualziation associated with figures 3-6 of the manuscript "Tracking demographic changes in individual coral colonies through repeated photogrammetric surveys", currently submitted for consideration at Remote Sensing in Ecology and Conservation.
