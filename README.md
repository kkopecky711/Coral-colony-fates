Code for analyzing data extracted from orthophoto mosaics of five ~25m^2 reef plots in Moorea, French Polynesia. These data are collected as a part of the Moorea Coral Reef Long Term Ecological Research site.

Datafiles are provided in this repository, as well as code for each individual analysis and visualziation associated with figures 2-5 of the manuscript "Tracking fates of coral colonies from individuals to reefscapes", currently submitted for consideration at Methods in Ecology and Evolution.
